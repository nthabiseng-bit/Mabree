## CHATAPP PART 3 - POE

### Description 
I'm allowing the user to access the chatapp which is the Quickchat and they are allowed to send messages, delete messages, search recipient, and to display the longest message. The user is required to register then login in order to send or store messages, and they are required to enter their username, phone number, and password.

### Running the application
1. Storing a message to JSON
2. Validate login before saving and storing
3. Menu system with switch-case
4. The overall flow of the app (Login/Register)(Main Menu)(Send Messages)(Store Messages)
5. Quit from the application.
